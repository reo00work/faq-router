# faq-router — 問い合わせ自動振り分けデモ

**公開デモ: https://faq-router.vercel.app**

「問い合わせの一次対応・カテゴリ振り分けを自動化できます」のポートフォリオ用実証デモ。  
**APIキー不要・標準ライブラリのみ**で動作します。

---

## これは何か

Webフォームや受信メールなどから届く問い合わせを自動でカテゴリ分類し、定型の一次返信文を生成するシステムです。

```
[問い合わせ文]
     ↓
① キーワードルール（高速・高信頼度）
     ↓ hit なし
② TF-IDF コサイン類似度（代表文との類似度比較）
     ↓ スコア低
③ LLM 分類（APIキー設定時のみ）
     ↓
[カテゴリ確定] → [定型一次返信文を出力]
```

| コンポーネント | 実装 |
|---|---|
| ルール分類 | キーワードマッチング（正規表現不要） |
| 意味分類 | TF-IDF + コサイン類似度（ゼロ依存） |
| LLM 分類 | Claude / GPT（任意・APIキー設定時のみ） |
| カテゴリ定義 | `categories.json`（ノーコードで編集可能） |

```
faq-router/
```

## 動かし方

### 前提
- Python 3.10 以上
- 追加パッケージのインストール **不要**（標準ライブラリのみ）

### 単一問い合わせの分類

```bash
cd faq-router
python3 router.py '料金を教えてください'
```

出力例:
```
問い合わせ: 料金を教えてください
カテゴリ  : 【料金】 （判定方法: キーワードルール）

一次返信文:
--------------------------------------------------
お問い合わせいただきありがとうございます。
料金・費用についてはご要望の内容・規模により異なります。
詳しいお見積りはメール（info@example.com）またはお問い合わせフォームよりお気軽にご相談ください。
通常 2 営業日以内にご回答いたします。
--------------------------------------------------
```

### サンプル一括テスト

```bash
python3 router.py --all
```

12 件のサンプル問い合わせを一括処理し、カテゴリ判定・一次返信を表示します。

### デバッグモード（スコア確認）

```bash
python3 router.py --debug '既存システムとの連携はできますか？'
```

出力例:
```
[DEBUG] 入力: 既存システムとの連携はできますか？
  [判定] キーワードルール → 技術質問

問い合わせ: 既存システムとの連携はできますか？
カテゴリ  : 【技術質問】 （判定方法: キーワードルール）
```

TF-IDF が使われた場合は各カテゴリのスコアも表示されます。

## Web版（ローカル・依存ライブラリなし）

CLIだと非エンジニアのクライアントには見せられないため、ブラウザで実際に
問い合わせ文→カテゴリ・一次返信をやり取りできる最小Webサーバーを同梱している
（`router.py` のカテゴリ定義ロード・分類ロジックをそのまま再利用、新規pip依存なし）。

```bash
cd faq-router
python3 server.py
# または任意のポートを指定
python3 server.py --port 8766
```

起動後、ブラウザで `http://localhost:8766` を開くと入力欄付きのチャットUIが表示され、
そのまま問い合わせ文を打ち込んでカテゴリ・判定方式・一次返信文を受け取れる。`Ctrl+C` で停止。

API経由で直接叩く場合（動作確認・自動テスト向け）:

```bash
curl -X POST http://localhost:8766/route \
  -H "Content-Type: application/json" \
  -d '{"question": "料金を教えてください"}'
```

`ANTHROPIC_API_KEY` / `OPENAI_API_KEY` 未設定でもCLI同様キーワード＋TF-IDFのみで動作する。

## カテゴリ定義のカスタマイズ

`categories.json` を編集するだけで**コード変更なし**にカテゴリを追加・変更できます。

```jsonc
{
  "categories": {
    "料金": {
      "keywords": ["料金", "費用", "いくら", ...],  // ① ルール用キーワード
      "examples": ["料金を教えてください", ...],     // ② TF-IDF 代表文
      "response": "一次返信テキスト"                // ③ 自動返信文
    },
    // 追加カテゴリもここに...
  }
}
```

## LLM 分類を有効にする（任意）

APIキーを設定するとキーワード・TF-IDF で判定できない曖昧な問い合わせも LLM が補完します:

```bash
# Anthropic Claude（推奨）
export ANTHROPIC_API_KEY=sk-ant-...
python3 router.py '相談があるのですが'

# または OpenAI
export OPENAI_API_KEY=sk-...
python3 router.py '相談があるのですが'
```

キーが未設定でもローカルルール + TF-IDF で動作します（APIキーの設定は任意）。

## 実証済み分類性能（ローカル・APIキーなし）

| 問い合わせパターン | 判定方法 | カテゴリ |
|---|---|---|
| 料金・費用・見積・コスト | キーワード | 料金 |
| 納期・スケジュール・締め切り | キーワード | 納期 |
| API・システム・技術・連携 | キーワード | 技術質問 |
| ちょっと相談があります | TF-IDF | その他 |
| 詳しく話を聞きたい | TF-IDF | その他 |

サンプル 12 件を **APIキーなし・ローカルのみ** で 12/12 正答。

## このデモで示せる技術

- **ハイブリッド分類設計**（ルール → 統計的 → LLM の3段階フォールバック）
- **TF-IDF ベクトル化**（標準ライブラリのみ・ゼロ依存での実装）
- **LLM の差し替え可能な設計**（環境変数でのプロバイダー切り替え）
- **ノーコード定義**（`categories.json` 編集でカテゴリ追加・返信文変更）
- **実用ユースケース**（問い合わせフォーム自動化・カスタマーサポート一次対応）
